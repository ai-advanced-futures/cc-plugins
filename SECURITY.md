# Security

Do not open a public issue for a security problem.

Report it with the private advisory form of this repository: **Security** tab, then **Report a vulnerability**. The form goes only to the maintainers.

Give these items in the report:

1. The plugin or skill, and its version from `.claude-plugin/plugin.json`.
2. The steps that show the problem.
3. What an attacker can do with it.

You get an answer in the advisory thread. The fix comes in a new version of the plugin.
