# Moore Core vs. Context Analysis Lens

## Purpose

Determine what percentage of the artifact represents true competitive differentiation (Core) versus necessary operational work that competitors can also do (Context), using Geoffrey Moore's framework from "Dealing with Darwin."

**Core thesis:** Companies create competitive advantage only through Core activities. Context activities consume resources and attention without creating differentiation. Ruthlessly distinguishing between the two is essential for survival.

## Definitions

### Core
Activities that create competitive differentiation today.
- Customers choose you BECAUSE of this, not just with it
- Competitors cannot easily replicate it
- Directly tied to the reason you win deals
- Worth protecting and investing in aggressively

### Context
Necessary activities that create no competitive differentiation.
- Required to operate but available to all competitors
- Customers expect this as table stakes — not a reason to choose you
- Should be optimized, outsourced, or automated
- Danger: teams confuse "important" with "differentiating"

## Core/Context Migration

Over time, Core becomes Context:
- Today's differentiating feature → tomorrow's table stakes
- The question is: "Is this Core TODAY?"
- What's Core at one company may be Context at another (it depends on strategy)

## Crossing the Chasm Application

Moore's lens also asks: is this ready to cross the chasm from early adopters to mainstream?
- Early market: passionate about the differentiator
- Mainstream: needs a "whole product" (complete solution)
- Chasm crossing requires focused Core investment + ruthless Context elimination

## Analysis Protocol

### Step 1: Catalog All Elements
List each element of the artifact that a customer or a competitor would notice (features, approaches, methods, components).

### Step 2: Classify Each Element
For each element:
- **CORE:** "Does a customer choose this solution BECAUSE of this element?"
- **CONTEXT:** "Would a customer be dissatisfied WITHOUT it, but not specifically choose it?"

### Step 3: Calculate Core Percentage
- Core elements / Total elements × 100
- >60% = Core Dominant → strong differentiator
- 40-60% = Balanced → mixed signals
- <40% = Context Dominant → commodity risk

### Step 4: Chasm Readiness
Is the Core strong enough to cross from early adopters to mainstream?

### Step 5: Score Output (1-5)
1 = <20% Core, mostly commodity context work
2 = 20-40% Core, limited differentiation
3 = 40-60% Core, balanced
4 = 60-80% Core, strong differentiator
5 = >80% Core, exceptional competitive position
