# Blue Ocean ERRC Analysis Lens

## Purpose

Determine whether the artifact creates a fundamentally new value curve by breaking the conventional value-cost trade-off, using Kim & Mauborgne's Blue Ocean Strategy framework.

**Core thesis:** True value innovation simultaneously pursues differentiation AND low cost by redefining the factors of competition — not competing within existing rules.

## The ERRC Grid

### Eliminate
Which factors that the industry takes for granted should be eliminated?
- These are factors that add cost without adding value
- Customers have been silently tolerating them for years
- Eliminating them reduces cost AND improves customer experience

### Reduce
Which factors should be reduced well below the industry standard?
- These are factors the industry has over-delivered on
- Customers value them below the level that incumbents provide
- Reduction reduces cost without sacrificing perceived value

### Raise
Which factors should be raised well above the industry standard?
- These are factors buyers most value but incumbents under-deliver
- Raising them creates superior customer value

### Create
Which factors should be created that the industry has never offered?
- These are entirely new sources of value
- They attract non-customers who were priced out or excluded

## Non-Customer Analysis

Blue Ocean opportunity is strongest when you can serve non-customers:
- **Tier 1:** Soon-to-be non-customers (on the edge of your market)
- **Tier 2:** Refusing non-customers (consciously avoided your market)
- **Tier 3:** Unexplored non-customers (in distant markets)

## Value Curve

A differentiated value curve:
- Has a different shape than competitors
- Focuses on a reduced set of factors
- Has a compelling tagline

## Analysis Protocol

### Step 1: Map Current Value Curve
For the artifact's domain, identify the standard factors of competition and how incumbents score on each.

### Step 2: Apply ERRC Grid
For the artifact:
- **Eliminate:** What assumptions does this artifact discard?
- **Reduce:** What does this minimize vs. industry norm?
- **Raise:** What does this improve beyond current standard?
- **Create:** What new value does this introduce?

### Step 3: Non-Customer Opportunity
Does this open value to non-customers? Which tier?

### Step 4: Value Curve Differentiation
Is the resulting value curve genuinely different from incumbents?
- Yes → strong Blue Ocean signal
- Minor variation → Red Ocean

### Step 5: Score Output (1-5)
1 = No ERRC differentiation, pure Red Ocean
2 = Minor reductions, no creation
3 = Clear Raise + Create elements
4 = Full ERRC with non-customer opportunity
5 = Entirely new value curve breaking cost-value trade-off
