# Launch Planning

## Purpose

Design a launch that matches the product's adoption stage, creates a measurable signal, and doesn't overpromise.

## Launch Types

| Type | When | Key Message | Audience |
|---|---|---|---|
| Beta | Pre-PMF validation | "Help us shape this" | Innovators + Early Adopters |
| Early Access | PMF signal confirmed | "Be first to get results" | Early Adopters |
| GA | Crossing the Chasm | "Ready for your team now" | Early Majority |
| Feature | Existing customers | "New capability available" | Current users |

## Launch Planning Protocol

### Step 1: Stage Assessment
Apply Moore's Chasm framework. Which launch type matches the current adoption stage?

### Step 2: AARRR Baseline
Set current metric for each AARRR stage. Launch success = measurable improvement in Activation and Acquisition.

### Step 3: Channel Selection
By stage: Beta → community forums + 1:1 outreach. EA → PR + email + referrals. GA → all channels + paid. Feature → in-product + email.

### Step 4: Message Architecture
Apply StoryBrand: what problem does this launch solve for the customer? All launch copy checked against Truth Tier.

### Step 5: Success Criteria
Define 3 measurable success metrics with targets and timeline.

### Step 6: Launch Calendar
Week-by-week plan: pre-launch → launch day → post-launch follow-up.

## Output
`launch-plan.json` with phases, activities, owners, and success metrics.
