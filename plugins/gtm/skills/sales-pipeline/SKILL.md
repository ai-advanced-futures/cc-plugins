# Pipeline Playbooks

## Purpose

Define what good looks like at every pipeline stage — with MEDDPICC rigor — so that no deal enters forecast without evidence of real opportunity.

## Pipeline Stage Design

For each stage, define:
- **Name**: Discovery → Technical Validation → Economic Buyer → Legal/Procurement → Closed Won
- **Entry Criteria**: what must be true for a deal to enter this stage
- **Exit Criteria**: what must be true to advance to next stage
- **Key Activities**: what actions move the deal forward
- **MEDDPICC Focus**: which dimension to advance at this stage

## MEDDPICC Scorecard

Score each dimension 0-2:
- 0 = Unknown / not pursued
- 1 = Known (they told you)
- 2 = Confirmed + documented

| Dimension | Score (0-2) | Evidence |
|---|---|---|
| Metrics (quantified business impact) | | |
| Economic Buyer (confirmed decision authority) | | |
| Decision Criteria (how they evaluate) | | |
| Decision Process (path to contract) | | |
| Identify Pain (confirmed business problem) | | |
| Champion (advocate selling for you) | | |
| Competition (who else is in the deal) | | |

**Total ≥ 12/16 = forecastable**

## Champion Test
"Can your champion present YOUR business case to the Economic Buyer without you in the room?"
If no: champion development is the #1 priority.

## Output
`pipeline-playbook.json` with stage definitions, MEDDPICC scorecard template, and avg_deal_size + avg_cycle_days.
