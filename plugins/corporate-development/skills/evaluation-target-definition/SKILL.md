# Target Definition

## Purpose
Define the ideal acquisition target profile through structured analysis of strategic fit and value creation potential.

## Overview
This skill guides the creation of a comprehensive target definition that serves as the foundation for all subsequent M&A activities. It transforms high-level strategic goals into concrete acquisition criteria.

## Definition Components

### 1. Opportunity Matrix (2x2)
Create a 2x2 matrix mapping:
- **Axis 1**: Strategic Value (Market Access, Technology, Talent, IP)
- **Axis 2**: Integration Complexity (Low, Medium, High)
- **Output**: Visual prioritization of opportunity types

### 2. Industry Selection
Identify target industries using:
- Market size and growth analysis
- Competitive landscape assessment
- Strategic alignment with existing capabilities
- Regulatory environment evaluation

### 3. SDE Valuation Approach
Define seller's discretionary earnings (SDE) parameters:
- Revenue range targets
- SDE multiples by industry/stage
- Deal size preferences (e.g., $5M-$50M)
- EBITDA vs SDE considerations for different business types

### 4. Limiter Categories

#### Geography
- Primary markets (e.g., North America, Europe)
- Secondary markets (expansion opportunities)
- Excluded regions (regulatory, operational constraints)

#### Business Model
- B2B vs B2C preferences
- Recurring revenue requirements
- Asset-light vs capital-intensive
- Technology/platform dependencies

#### Deal Breakers
- Regulatory/compliance issues
- Cultural misalignment indicators
- Technology incompatibilities
- Financial red flags

### 5. Target Statement Generation
Synthesize analysis into a clear target statement:
```
"We seek [business type] in [industry/geography] with [revenue/SDE range]
that provides [strategic value] and can be integrated at [complexity level]."
```

## Output Artifact
- **File**: `TARGET-DEFINITION.md`
- **Location**: Discovery session directory
- **Format**: Structured markdown with matrices, criteria lists, and target statement
- **Usage**: Input for target search and screening processes

## Usage
```bash
/corporate-development:evaluation-target-definition
```

The skill will:
1. Prompt for strategic objectives
2. Guide through each definition component
3. Generate opportunity matrix visualization
4. Write the TARGET-DEFINITION.md document
5. Provide target statement for search activities

## Next Steps

1. Use output to guide target search activities
2. Develop screening criteria from limiters
3. Create industry-specific evaluation rubrics
