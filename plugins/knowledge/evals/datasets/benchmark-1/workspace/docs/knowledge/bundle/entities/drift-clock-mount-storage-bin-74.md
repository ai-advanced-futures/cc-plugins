# Drift clock mount storage bin 74

Storage bin 74 in the calibration room holds adapters for the Drift clock mount.

The optics custodian checks the bin label at the start of each month.

The bin has room for 207 adapters; damaged adapters go in a separate red box.

Keep the Drift clock mount at least 46 centimetres from the drying rack.
