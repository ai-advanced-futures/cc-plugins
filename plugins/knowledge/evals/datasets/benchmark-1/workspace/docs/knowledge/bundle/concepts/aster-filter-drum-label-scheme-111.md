# Aster filter drum label scheme 111

Label scheme 111 uses a green triangle on the case of the Aster filter drum.

The triangle marks the approved carrying side, not inspection status.

An unreadable triangle must be replaced before the case leaves storage.

Use tray 1 for loose parts removed from the Aster filter drum.
