# Beacon sensor tray storage bin 42

Storage bin 42 in the east annex holds adapters for the Beacon sensor tray.

The instrument checker checks the bin label at the start of each month.

The bin has room for 175 adapters; damaged adapters go in a separate red box.

Keep the Beacon sensor tray clear of the marked aisle by at least 40 centimetres.
