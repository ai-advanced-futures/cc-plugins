# Aster filter drum cleaning rule 51

Cleaning rule 51 applies to the handles of the Aster filter drum.

Use a damp cloth, then dry the surface before storage.

Do not apply this rule to lenses, wiring, bearings, or sealed housings.

The handling team for the Aster filter drum must include 4 trained operators.
