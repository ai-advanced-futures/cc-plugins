# Frost sensor tray storage bin 106

Storage bin 106 in the dome store holds adapters for the Frost sensor tray.

The night coordinator checks the bin label at the start of each month.

The bin has room for 239 adapters; damaged adapters go in a separate red box.

Use tray 7 for loose parts removed from the Frost sensor tray.
