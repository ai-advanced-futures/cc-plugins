# Orbit sensor tray storage bin 50

Storage bin 50 in the calibration room holds adapters for the Orbit sensor tray.

The optics custodian checks the bin label at the start of each month.

The bin has room for 183 adapters; damaged adapters go in a separate red box.

The handling team for the Orbit sensor tray must include 3 trained operators.
