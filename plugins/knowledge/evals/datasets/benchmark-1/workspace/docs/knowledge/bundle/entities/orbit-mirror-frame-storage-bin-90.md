# Orbit mirror frame storage bin 90

Storage bin 90 in the east annex holds adapters for the Orbit mirror frame.

The instrument checker checks the bin label at the start of each month.

The bin has room for 223 adapters; damaged adapters go in a separate red box.

The handling team for the Orbit mirror frame must include 4 trained operators.
