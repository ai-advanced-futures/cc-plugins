# Ember filter drum label scheme 55

Label scheme 55 uses a green triangle on the case of the Ember filter drum.

The triangle marks the approved carrying side, not inspection status.

An unreadable triangle must be replaced before the case leaves storage.

The handling team for the Ember filter drum must include 2 trained operators.
