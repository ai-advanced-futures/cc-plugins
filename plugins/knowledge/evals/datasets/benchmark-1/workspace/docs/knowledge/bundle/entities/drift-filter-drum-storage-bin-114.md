# Drift filter drum storage bin 114

Storage bin 114 in the east annex holds adapters for the Drift filter drum.

The instrument checker checks the bin label at the start of each month.

The bin has room for 247 adapters; damaged adapters go in a separate red box.

Keep the Drift filter drum at least 48 centimetres from the drying rack.
