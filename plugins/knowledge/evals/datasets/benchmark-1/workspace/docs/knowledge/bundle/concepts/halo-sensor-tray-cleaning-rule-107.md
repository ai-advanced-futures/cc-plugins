# Halo sensor tray cleaning rule 107

Cleaning rule 107 applies to the handles of the Halo sensor tray.

Use a damp cloth, then dry the surface before storage.

Do not apply this rule to lenses, wiring, bearings, or sealed housings.

Use tray 8 for loose parts removed from the Halo sensor tray.
