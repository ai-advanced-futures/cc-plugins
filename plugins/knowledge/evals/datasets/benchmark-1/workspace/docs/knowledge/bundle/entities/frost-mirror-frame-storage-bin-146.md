# Frost mirror frame storage bin 146

Storage bin 146 in the calibration room holds adapters for the Frost mirror frame.

The optics custodian checks the bin label at the start of each month.

The bin has room for 279 adapters; damaged adapters go in a separate red box.

Use tray 3 for loose parts removed from the Frost mirror frame.
