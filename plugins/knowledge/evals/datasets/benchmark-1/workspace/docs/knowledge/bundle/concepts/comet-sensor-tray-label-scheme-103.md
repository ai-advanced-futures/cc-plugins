# Comet sensor tray label scheme 103

Label scheme 103 uses a green triangle on the case of the Comet sensor tray.

The triangle marks the approved carrying side, not inspection status.

An unreadable triangle must be replaced before the case leaves storage.

Record the Comet sensor tray case temperature after 5 minutes indoors.
