# Cobalt wheel stand storage bin 2

Storage bin 2 in the repair hall holds adapters for the Cobalt wheel stand.

The parts custodian checks the bin label at the start of each month.

The bin has room for 75 adapters; damaged adapters go in a separate red box.

Keep the Cobalt wheel stand clear of the marked aisle by at least 21 centimetres.
